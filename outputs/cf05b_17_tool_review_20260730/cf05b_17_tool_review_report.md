# CF-05B 17工具科学适用域AI预审

## 结论

17个代码实现并不等于17个已经满足CF-05科学接受标准的工具。本轮静态审查和定向诊断得到：

- 修订后才能进入接受候选：14项；
- 补充边界说明后可继续复核：3项；
- 严重风险：5项；
- 人工确认：0项；
- CF-05正式接受：0项。

## 已复现的关键问题

1. A001对1 kg→m返回success和数值1.0；
2. A002/A003会静默忽略Fe2O3abc的非法尾随字符；
3. B002名为NASA多项式，但实际调用Shomate；
4. B003把摩尔焓差直接乘mass(g)，存在量纲错误；
5. B005组合H°−H°298.15与绝对S°，参考态不一致；
6. B008的pressure输入不影响结果；
7. B009在T=0时进入INTERNAL_ERROR；
8. C002的1 eV分支得到D/D0=1，而按摩尔换算应约为9.1×10⁻⁶。
