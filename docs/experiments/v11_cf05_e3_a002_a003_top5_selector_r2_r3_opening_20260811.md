# CF-05 E3 A002/A003 Top-5 Selector R2/R3 开启包

## 目的

R1 的 192 个单元中有 188 个端到端正确、3 个双工具调用和 1 个供应商 HTTP 522。为区分稳定方法差异与单次运行波动，本包为全部 192 个基础单元各构建一个 R2 和一个 R3 新重复，共 384 个请求。

这不是对 R1 四个失败单元的重试。R1 原始结果保持不变，R2/R3 对所有方法、任务、工具池规模和池重复提供相同的新运行机会。

## 冻结范围

与 R1 相比，仅改变：

- `model_run_repeat`：R2 或 R3；
- 新的 `cell_id`、顺序号和来源追踪字段。

以下内容逐单元与 R1 完全相同：

- 16 条任务文本；
- 192 个五工具 Schema 视图；
- Lexical、Dense v2、Hierarchical 三种方法；
- 提示词；
- 工具顺序；
- `thinking disabled`；
- `max_tokens=256`；
- `temperature=0` 和 `tool_choice=auto`。

384/384 个 payload 已通过与 R1 完全相等检查。每个 R1 基础单元恰好对应一个 R2 和一个 R3 单元。

## 当前状态

开启包已经物化，但外部 API 执行尚未授权：

- 外部 API 调用：0；
- 工具执行：0；
- 允许自动重试：否；
- 允许复用 R1 响应：否；
- 访问独立验证集：否；
- 确认性推断：否。

只有获得绑定本开启包 manifest 的独立明确授权后，才能执行这 384 个请求。
