审计没有用弱相关工具填满近邻槽位，也没有因为池尚不可构造而修改冻结假设。

## 2. 为什么120条目录不够构造120规模控制剂量池

`controlled_dose`要求同一无关干扰基底分别加入0、4、8个近邻，同时保持总工具数不变。

若工具池规模为`S`、最大剂量为8：

```text
单一近邻类型所需最小目录规模 = S + 8
两个互斥近邻类型所需最小目录规模 = S + 16
```

因此在`S=120`时：

```text
词法或契约单类型：至少128条
词法＋契约错配双类型：至少136条
```

当前目录只有120条。它可以形成120规模的`mixed_realistic`池，但无法形成共享同一无关基底的120规模0/4/8替换池。

| 池规模 | 单类型最小目录 | 双类型最小目录 | 当前120条是否满足双类型容量 |
|---:|---:|---:|---|
| 17 | 25 | 33 | 是 |
| 50 | 58 | 66 | 是 |
| 100 | 108 | 116 | 是 |
| 120 | 128 | 136 | 否 |

## 3. 五个目标的近邻审计结果

词法筛选使用冻结目录字段上的字符二元组Dice，可复算且不读取模型实验结果。契约错配近邻必须同时满足：

1. 输入和输出均达到功能相似阈值，或核心方法完全相同；
2. 双方均存在结构化契约字段；
3. 至少一个适用系统、模型版本或服务状态字段明确不匹配。

结果如下：

| 目标 | 算法词法候选 | 可证明契约错配近邻 | 同时满足两类8近邻 |
|---|---:|---:|---|
| A001 单位换算 | 0 | 0 | 否 |
| A002 化学式解析 | 1 | 0 | 否 |
| A003 摩尔质量计算 | 12 | 0 | 否 |
| A004 成分归一化 | 1 | 0 | 否 |
| B019 杠杆规则计算 | 8 | 0 | 否 |

A002与A003虽然都接受化学式，但输出功能不同，因此不能仅因共享输入就判为功能重叠近邻。

## 4. 该结果意味着什么

当前不能宣称：

- 已完成E3 0/4/8控制剂量池；
- 已具备H3在120工具下的主要确认性比较；
- 120条Schema自然包含足够近邻；
- 可以把低相似工具重新标为高相似近邻。

仍然可以继续：

- 使用现有120条构造`mixed_realistic`规模池；
- 执行17/50/100/120 Schema容量可行性先导；
- 扩展路由目录和结构化契约；
- 在不查看正式结果前重新审查H3的可执行性。

## 5. 下一决策

保持H3的120规模双类型确认性设计时，需要：

1. 将路由候选宇宙扩展到至少136条独立目录项；
2. 新增条目不能只是无关工具，必须为目标工具提供足够的词法近邻和结构化契约错配近邻；
3. 为近邻记录输入、输出、相态、温区、系统、版本和可用性等机器可比较字段；
4. 完成家族独立性和不可替代性审计。

若无法获得上述真实目录，则应在查看E3正式结果前书面修订H3，把控制剂量主要规模降至100；120规模继续只用于`mixed_realistic`的H4。当前审计不自动作出该理论选择。
