## 3. 防循环与泄漏审计

| 标识 | 交叉数 |
|---|---:|
| `task_id` | 0 |
| `task_pair_id` | 0 |
| `base_task_group_id` | 0 |

两者允许共享相同的五个`verified_core`工具家族，以检验规则在同一工具家族内向新任务迁移；不允许共享具体任务、任务对或基础任务组。

同时固定以下边界：

- 同一运行不得既生成收益标签又证明门控性能；
- `tool_benefit`不写回基础真值；
- AI银标不升级为确认性金标准；
- E1c只作为端到端机制证据，不并入E1b主要收益效应；
- 135个成对重复不是135个独立样本，功效分析必须按基础任务组聚类。
