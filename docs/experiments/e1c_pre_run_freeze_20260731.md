## 3. 为什么需要六个条件

只比较“完全自主”与“No Tool”无法解释失败原因。本协议固定：

- C0测无工具基线；
- C1测验证工具与Oracle参数上限；
- C2隔离边界识别；
- C3隔离参数生成；
- C4测普通Direct FC；
- C5测加入冻结边界后的自主FC。

每个单元按照固定优先级归因到最早失败阶段，即使最终答案碰巧正确，过度调用或工具错选仍会保留为机制错误。

## 4. 离线实现证据

离线模拟已覆盖：

- 六个条件完整执行；
- CALL和ANSWER两类任务；
- 单工具调用解析；
- 工具选择正确性；
- 参数完全匹配；
- 模型门控JSON解析失败；
- “答案正确但过度调用”的边界错误归因；
- 开发快照拒绝混入后置任务。

这些测试证明运行器接口可执行，不代表真实模型表现。
