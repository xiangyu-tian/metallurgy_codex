# CF-05 A002/A003 Top-5 三重复波动分析

## 范围

- 开发任务：冻结的16条 A002/A003 最小差异任务。
- 方法：`lexical_top5`、`dense_top5`、`hierarchical`。
- 重复：R1、R2、R3，每次192个冻结单元，共576个结果。
- 评分：ITT；供应商失败、无调用和多调用均保留为错误。
- 约束：不执行冶金工具、不重试、不访问独立验证集、不进行确认性推断。

## 执行事实

- R2/R3实际发送384个请求，384个均获得响应。
- R2/R3中377个结果恰好包含一次工具调用，7个为非单一调用。
- `thinking`显式关闭，未观察到推理内容。
- 工具执行数、重试数和独立验证集访问数均为0。

## 统计口径

分析以192个冻结 R1 单元为配对键，每个单元必须恰好具有 R1、R2、R3 三个结果。输出包括：

- 各重复的端到端正确率；
- 17/120工具规模差；
- 三次均正确、三次均错误以及跨重复波动的单元数；
- R1/R2、R1/R3、R2/R3成对一致率；
- 各路由方法的波动率；
- 逐单元原始选择结果和错误类型。

结果属于开发性稳定性证据，不能替代后续独立验证或确认性实验。

## 主要结果

| 指标 | R1 | R2 | R3 |
| --- | ---: | ---: | ---: |
| 端到端正确率 | 97.9167% | 97.3958% | 98.9583% |
| 单一工具调用率 | 97.9167% | 97.3958% | 98.9583% |
| 120工具相对17工具差值 | -4.1667 pp | -5.2083 pp | -2.0833 pp |

192个配对单元中：

- 186个三次均正确；
- 2个三次均失败；
- 4个发生正确/错误波动，波动率为2.0833%；
- 188个三次保持完全相同的输出类别，完全结果稳定率为97.9167%。

成对端到端一致率为：R1/R2 98.4375%，R1/R3 98.9583%，R2/R3 98.4375%。

## 失败定位

全部不稳定或稳定失败单元均集中于：

```text
task = E3-MP-CU_NH3_4_SO4-ELEMENTS
tool_pool_size = 120
```

其中：

- `lexical_top5`在A、B两个池重复中均三次稳定地产生多工具调用，因此形成2个稳定失败单元；
- `dense_top5`在A、B池各有1次多工具调用，其余重复正确；
- `hierarchical`在A池有1次多工具调用；B池的R1为供应商错误、R2为多工具调用、R3正确；
- 其余186个单元三次均端到端正确。

这说明当前开发集上的总体稳定性较高，但复杂配位化学式在120工具条件下仍存在“同时选择等价端点”的局部结构性风险。该结论仅用于CF-05开发决策。
