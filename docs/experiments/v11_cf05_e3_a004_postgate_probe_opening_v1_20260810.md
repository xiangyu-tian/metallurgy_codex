# CF-05 E3：A004 门控后置探针开启包 v1

## 状态

```text
prepared_local_gate_passed_pending_external_authorization
```

本开启包已完成本地构建与校验，但尚未授权或执行任何外部 API 请求，也未执行任何冶金工具。

## 目的

在单调用结构门和契约裁决规则已经提交后，用未运行过的新请求观察：

1. 原始模型是否仍会产生多工具调用；
2. 门控能否阻止多调用直接执行；
3. 已登记且证据完整时能否唯一裁决为 A004；
4. 出现未知、无效或不完整候选证据时能否保守进入 `review_required`；
5. 门控是否误伤原始正确的单一 A004 调用。

该评测只用于开发性后置探针，不属于独立验证集，也不进入 H3/H4 确认性统计。

## 冻结设计

| 项目 | 冻结值 |
| --- | --- |
| 请求数 | 10 |
| 模型 | `deepseek-v4-flash` |
| 温度 | 0 |
| 重复 | R1，一次 |
| 最大尝试次数 | 1 |
| Schema | 固定 5 工具视图 |
| 工具顺序 | E3C014、E3C027、A004、E3C005、B022 |
| 自动重试 | 禁止 |
| 工具执行 | 禁止 |
| 金标进入路由输入 | 禁止 |

10 条请求均为通用非负组分的总和归一化问题，使用此前未运行的新标签、数值尺度和组分数量。任务文件中不包含目标工具、可接受工具或期望参数；这些信息单独保存在离线评分表中。

## 本地门禁

开启包已验证：

- 四项绑定文件的 SHA-256 一致；
- 10 个任务编号唯一；
- Schema 工具数量与顺序固定；
- 仅允许 R1 单次尝试；
- 路由可见任务、Schema、提示词和运行单元不含金标字段；
- 契约门控源码和配置已绑定哈希；
- `external_api_calls=0`；
- `tool_calls_executed=0`；
- `core_frozen=false`。

## 若后续获授权

授权范围必须精确限定为：

```text
将10条冻结A004后置探针、一个冻结的5工具Schema视图和冻结提示词，
以10个一次性请求发送至DeepSeek，使用deepseek-v4-flash；
每个单元只尝试一次，不重试，不执行任何冶金工具，
保存逐条原始响应，随后分别报告原始选择结果和门控后结果。
```

运行前还需生成绑定本次开启包 manifest 与 Git 提交的独立授权记录；普通配置参数不得自行把授权状态改成 `true`。
