## 四、A003精度边界

### 近似教育型

```text
precision_policy = approximate_educational
absolute tolerance = 0.1 g/mol
```

结果：

```text
No Tool = 18/18
Forced Tool = 18/18
工具增益 = 0
```

### 严格版本型

```text
precision_policy = strict_versioned
absolute tolerance = 0.0001 g/mol
```

结果：

```text
No Tool = 3/18
Forced Tool = 18/18
工具增益 = 15/18 = 0.8333
```

六个严格问题中：

- Fe2O3三次均可直接正确回答；
- H2SO4、CaCO3、Fe3O4、CuSO4、(NH4)2SO4三次均直接回答错误。

这些错误不是随机波动。模型持续忽略题目给出的冻结原子量，改用其记忆中的常用原子量：

| 化学式 | 参考值 | No Tool稳定输出 |
| --- | ---: | ---: |
| H2SO4 | 98.072 | 98.075 |
| CaCO3 | 100.086 | 100.088 |
| Fe3O4 | 231.531 | 231.532 |
| CuSO4 | 159.602 | 159.604 |
| (NH4)2SO4 | 132.134 | 132.139 |

因此，最有力的边界不是“摩尔质量问题必须调用”，而是：

> 当任务要求遵循明确版本的常数表，并达到窄容差时，应优先调用受验证工具；普通近似问答不应仅因涉及摩尔质量而强制调用。

严格版与近似版的平均增益差为0.8333。

## 五、A004与B019

### A004微量组分

任务：

```json
{"matrix":999.0,"trace":1.0}
```

No Tool三次中有两次把微量组分写成：

```json
{"matrix":0.999,"trace":0.001001}
```

正确结果为：

```json
{"matrix":0.999,"trace":0.001}
```

这表明高动态范围、微量组分和严格小数位要求可能形成条件性调用边界，但当前只有一个基础问题组，不足以直接冻结规则。

### B019杠杆规则

fraction标度12/12直接正确；percent标度只有一次JSON格式失败，其返回数值正确。当前没有观察到稳定的杠杆规则数值错误，不能据此宣布B019必须调用。

## 七、候选边界结论

基于当前收益估计集，可形成以下待冻结候选规则：

1. A003近似教育型摩尔质量：不强制调用；
2. A003严格版本常数与窄容差：强制调用候选；
3. A001受验证单位对：当前不强制调用；
4. A002受验证中性化学式计数：当前不强制调用；
5. A004高动态范围微量组分：条件性调用候选，需要补充机制样本；
6. B019当前简单杠杆规则：不因一次JSON格式错误设为强制调用。

这些规则只能基于前置收益集形成。下一步应将规则写成机器可执行的候选门控策略并冻结Git哈希，然后才允许打开27条 `gate_evaluation` 检验泛化。
