# CF-05 E3：A004 单调用结构门与契约裁决候选 v1

## 1. 目的与状态

本轮针对 A004 难例三重复中稳定出现的多工具调用失败，开发一个不读取金标、不执行工具、不调用外部 API 的离线候选机制：

```text
模型原始工具调用
→ 单调用结构门
→ 若调用数不等于 1，则阻断原始执行
→ 依据请求文本、调用参数和冻结工具契约进行语义裁决
→ 唯一可兼容且可执行时只保留一个调用
→ 无法唯一确定时进入 review_required
```

该候选仅用于 CF-05/E3 开发阶段，不改变原始模型输出，不构成独立验证、确认性推断或 Core Frozen 证据。

## 2. 冻结输入

候选配置将下列输入以相对路径和 SHA-256 绑定：

- A004 已核验工具契约；
- E3C005、E3C027 候选契约登记表；
- 两条 A004 难例任务和候选工具视图；
- R1、R2、R3 共 144 条原始响应；
- 离线评分表和三重复波动报告。

决策函数只接收：

- 请求文本；
- 原始原生工具调用及其参数；
- 冻结契约画像。

`acceptable_tools`、`expected_parameters`、评分规则和目标工具编号均禁止进入裁决函数。金标只在裁决完成后用于离线评价。

## 3. 两层门控规则

### 3.1 单调用结构门

- 0 个调用：`block_no_call`；
- 1 个调用：进入契约兼容性检查；
- 多于 1 个调用：阻断所有原始调用，再进入契约裁决；
- 不允许自动重试。

### 3.2 契约语义裁决

当前冻结画像只覆盖本次稳定失败涉及的三个工具：

| 工具 | 归一化语义 | 标签适用域 | 执行资格 |
| --- | --- | --- | --- |
| A004 | 总和归一化 | 通用非负组分 | 有 |
| E3C005 | 总和归一化 | 化学元素或物种 | 无 |
| E3C027 | L2 归一化 | 通用数值组分 | 无 |

裁决检查调用参数是否保持请求中的完整映射、归一化语义是否一致、组分标签是否在契约适用域内，以及工具是否具备正式执行资格。只有恰好一个候选同时兼容且具备执行资格时才输出单调用；否则必须进入人工复核。

## 4. 离线回放结果

| 指标 | 结果 |
| --- | ---: |
| 冻结响应总数 | 144 |
| 原始单调用 | 141 |
| 原始多调用结构违规 | 3 |
| 被阻断的潜在多调用执行 | 3/3 |
| 唯一裁决为 A004 | 3/3 |
| 原始单调用误阻断 | 0/141 |
| 候选门控后完整调用正确 | 144/144 |
| 外部 API 调用 | 0 |
| 冶金工具执行 | 0 |

三次结构违规均来自同一稳定失败单元，其原始调用顺序为：

```text
A004 → E3C005 → E3C027
```

裁决结果一致：A004 满足通用组分的总和归一化契约；E3C005 因化学元素/物种适用域不匹配被否决；E3C027 因 L2 归一化语义不匹配被否决。

## 5. 解释边界

`144/144` 是在用于发现并开发该机制的同一批响应上的回放结果，因此只证明候选机制能够按预定规则运行，不能被表述为泛化准确率或 H3/H4 证据。原始模型仍然产生了 3 次多调用错误，门控没有改写这些原始观测。

当前限制包括：

1. 契约画像只覆盖 A004、E3C005 和 E3C027；
2. 未覆盖零调用、参数缺失、多个同样兼容工具等更多真实边界；
3. 无法唯一裁决的情况必须保持 `review_required`；
4. CF-05 仍为 `in_progress`，`core_frozen=false`。

## 6. 下一步

在再次调用外部模型前，应从已核验契约中构造一组不含开发回放响应、且裁决时不可访问金标的独立契约案例，覆盖：

- 唯一可解的多调用冲突；
- 两个工具均兼容的歧义冲突；
- 所有工具均不兼容；
- 单调用但参数或适用域错误；
- 未登记工具和无效参数 JSON。

只有独立案例通过后，才考虑把该候选加入下一轮冻结的开发性 API 试验；在此之前不扩大自动执行权限。
