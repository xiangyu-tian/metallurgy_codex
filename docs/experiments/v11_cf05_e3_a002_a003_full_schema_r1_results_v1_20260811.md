- 5条没有形成单一函数调用，均以`finish_reason=length`结束；
- 1条选择了正确的A002，但参数JSON被长度截断；
- 6条端到端失败全部发生于120工具条件；
- 120-A为11/16端到端成功，120-B为15/16；
- 17-A和17-B均为16/16。

## 必须披露的传输混杂

开启配置声明`thinking=disabled`，但冻结请求载荷没有显式携带`thinking`字段。DeepSeek的64个响应全部包含`reasoning_content`或reasoning tokens，且`max_tokens=256`。因此120工具条件的失败更可能反映：

```text
更长Schema → 推理输出占用预算 → 函数调用被截断
```

而不是已经证明：

```text
工具规模增加 → A002/A003语义辨别能力下降
```

所以本轮是有效的开发诊断，但不能用于确认性结论。R1结果必须原样保留，不得重跑覆盖。
