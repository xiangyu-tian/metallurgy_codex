## 模型列表

### 1. 🔬 热力学推理 `thermodynamics`

| 项目 | 内容 |
|------|------|
| **计算类型** | ✅ **真实计算** — 内置热化学数据库，ΔG = ΔH − T·ΔS |
| **输入参数** | `reaction`（反应式）、`temperature`（温度，默认 1600°C） |
| **输出字段** | 反应式、反应名称、温度、ΔH°、ΔS°、ΔG、平衡常数 K、反应方向 |
| **特殊逻辑** | CaCO₃ 分解反应额外计算理论分解温度；不支持的返回可用反应列表 |

**内置 10 种反应：**

| # | 反应式 | 名称 | ΔH (kJ/mol) | ΔS (J/mol·K) |
|---|--------|------|-------------|--------------|
| 1 | C + O₂ → CO₂ | 碳完全燃烧 | −393.5 | 2.9 |
| 2 | 2C + O₂ → 2CO | 碳不完全燃烧 | −221.0 | 179.2 |
| 3 | FeO + C → Fe + CO | 氧化亚铁碳还原（直接还原） | 158.0 | 150.0 |
| 4 | Fe₂O₃ + 3CO → 2Fe + 3CO₂ | 赤铁矿间接还原 | −24.7 | 15.6 |
| 5 | Fe₃O₄ + 4CO → 3Fe + 4CO₂ | 磁铁矿间接还原 | −14.5 | 10.2 |
| 6 | CaCO₃ → CaO + CO₂ | 碳酸钙分解（石灰石煅烧） | 178.3 | 160.6 |
| 7 | SiO₂ + 2C → Si + 2CO | 二氧化硅碳还原（工业硅冶炼） | 689.6 | 359.3 |
| 8 | 2FeO + Si → 2Fe + SiO₂ | 硅还原氧化亚铁（脱氧反应） | −527.4 | −52.8 |
| 9 | MnO + C → Mn + CO | 氧化锰碳还原 | 276.1 | 151.6 |
| 10 | Fe₂O₃ + 2Al → 2Fe + Al₂O₃ | 铝热反应 | −851.5 | −38.0 |

**反应方向判定阈值：**

| ΔG 范围 | 判定 |
|----------|------|
| < −10 kJ/mol | 正向强烈自发 |
| −10 ~ 0 kJ/mol | 正向自发 |
| 0 ~ 10 kJ/mol | 逆向自发（需外界能量输入） |
| > 10 kJ/mol | 逆向强烈自发（需大量外界能量输入） |

### 2. 🔥 转炉炼钢工艺优化 `converter`

| 项目 | 内容 |
|------|------|
| **计算类型** | 模拟 — 终点预测带随机偏移 |
| **输入参数** | `siContent`（铁水 Si%）、`targetCarbon`（目标碳%）、`steelTemp`（温度）、`oxygenFlow`（氧流量） |
| **输出字段** | 铁水 Si 含量、目标碳含量、预测终点碳、预测终点温度、预计氧耗、炉渣碱度、氧枪流量建议 |

**计算逻辑：**
- 终点碳 ≈ 目标碳 + 随机偏移 (±0.01%)
- 终点温度 ≈ 输入温度 + 随机偏移 (±10°C)
- 氧耗 = Si% × 8 + 目标碳% × 15 + 随机 (±5)
- 炉渣碱度 = 3.2 + 随机偏移 (±0.4)

### 3. 🏭 高炉低碳运行分析 `blastfurnace`

| 项目 | 内容 |
|------|------|
| **计算类型** | 公式计算 — 固定碳排放系数 |
| **输入参数** | `cokeRate`（焦比，默认 360）、`coalRate`（煤比，默认 160）、`production`（日产量，默认 5000）、`oreGrade`（矿品位） |
| **输出字段** | 焦比、煤比、入炉矿品位、日产量、日碳排放量、碳排放强度、较基准降碳、碳利用效率 |

**计算逻辑：**
- 碳排放 = (焦比 × 2.86 + 煤比 × 2.45) × 产量 / 1000
- 基准 = (380 × 2.86 + 170 × 2.45) × 产量 / 1000
- 碳排放强度 = 碳排放 / 产量

### 4. 📊 连铸质量辅助决策 `casting`

| 项目 | 内容 |
|------|------|
| **计算类型** | 模拟 — 质量指标带随机偏移 |
| **输入参数** | `steelGrade`（钢种）、`sectionSize`（断面）、`castingSpeed`（拉速，默认 1.2）、`superheat`（过热度，默认 30） |
| **输出字段** | 钢种、断面、拉速、过热度、中心偏析指数、疏松指数、表面裂纹指数、综合质量评分 |

**质量评分规则：**
| 评分范围 | 判定 | 建议 |
|----------|------|------|
| ≥ 90 | 质量优良 | 可正常生产 |
| 80 ~ 90 | 质量良好 | 建议适当降低拉速 |
| < 80 | 质量一般 | 建议检查过热度与冷却制度 |
